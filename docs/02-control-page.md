# サービスページ仕様書
## 欠席代行サービス「オフライン」

# 代行対応管理ページ
担当スタッフ：準備中

このページでは、欠席代行サービス「オフライン」の内部処理を確認できます。  
PHASE1 の異常（レビューの違和感）を確認したプレイヤーは、  
ここで **写真の変化という視覚的異常** を発見し、`offlinePhase` を **phase2** へ進行させます。

---

## 1. localStorageキー

`offlinePhase`

### 使用する値
- phase0：初期状態（通常サイト）
- phase1：レビューの異常を発見
- phase2：写真の異常を発見（実験棟への変化）
- phase3：研究資料ページ閲覧 → フォーム異常へ遷移
- phase4：真相ページ解放

---
# 2. PHASE1の異常（レビューの違和感）

プレイヤーは「お客様の声」で以下の異常を確認します。

> 「昨日は休んでいたはずなのに、同僚から『昨日○○さんと話してたよね』と言われました」

スタッフ返信：

> 「ご契約内容とは異なる対応が実施された可能性があります。現在確認しております。」

この時点で `offlinePhase = "phase1"` になります。

---

# 3. PHASE2への進行：写真の異常を発見

PHASE1後、サービス紹介内の写真が変化します。

- **通常時**：一般的なオフィス風景  
- **PHASE1後**：奥の「STAFF ONLY」が **「実験棟」** に変化

この写真の変化を確認すると `offlinePhase = "phase2"` へ更新されます。

---

# 4. 写真クリックで研究資料ページへ遷移

プレイヤーが写真をクリックすると、  
**material.html** が解放されます。

## 6. 送信後の異常演出

フォーム送信後、ページ遷移は行われず、

3秒後、自動で **真相ページ** へ遷移します。

---

## 7. PHASE4へ更新
解析演出が完了した時点で  
`offlinePhase = "phase4"` に更新されます。

---

## 8. PHASE4後の状態変化


真相ページを閲覧し、「サービスを開始する」ボタンを押すと  
TOPページへ戻ります。

このタイミングで、サイト右上の表示が以下のように変化します。

- **担当スタッフ：準備中 → 担当スタッフ：稼働中**

また、ページ下部に以下が追加されます。

- X共有ボタン  
  「担当スタッフの準備が整いました。このサービスを必要としている方へ共有してください。」

---

## 9.  状態更新（localStorage）

真相ページの解析演出が完了した時点で  
`offlinePhase = "phase4"` に更新されます。

TOPページへ戻った際に、  
`offlinePhase === "phase4"` の場合のみ右上表示を **「稼働中」** に切り替えます。

# 13. アクセシビリティ

・操作対象はbutton要素
・Enter / Space対応
・フォーカスリングを消さない
・aria-labelを設定
・改変後の情報へフォーカス可能
・aria-liveを使用

# 15. 禁止事項

・phase0で異常を強調しない
・phase1で複数の新規クリック対象を追加しない
・血液や残虐表現を使用しない
・ホラーサイト化しない
