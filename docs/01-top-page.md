# サービスの特徴

・きめ細かな対応　お客様の状況をヒアリングし、自然な受け答えを行います。
・相手との関係性を配慮　先生・上司・友人など、相手に合わせた対応をいたします。
・欠席後のフォローまで対応　必要に応じて翌日の連絡や調整も承ります。
